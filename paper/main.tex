\section*{Data and code availability}
All data are synthetic and are regenerated by the code from fixed seeds. The
model, every estimator, every experiment script, the result files (JSON) behind every
number, and the figure scripts (each writing an audit file that lists every
plotted number with the run artifact it comes from) are available at
\url{https://github.com/aidxhxr/PINN-Research/tree/paper-v1}, the tagged state
from which this paper was built (paper sources in \texttt{research-paper-final/},
with \texttt{REPRODUCE.md} linking every figure and every number quoted only in
the text to its script and run).
