## Transcriptions

### Item 21 — Piskovsky, "Turing instabilities for three interacting species" (arXiv:2405.14682v1)

Setup. dn_i/dt = f_i(n), unique stable steady state n*; RD system ∂t n_i = d_i ∂²_x n_i + f_i(n). J(k²) = J − k² diag(d_1,…,d_N).

Definition 1. n* admits an instability if some k gives J(k²) an eigenvalue with positive real part. If every such eigenvalue is real for every k it is a **Turing instability**; if some are non-real it is a **Turing-Hopf instability**.

Characteristic equation of J(k²): p(λ) = λ³ − c_2(k²)λ² + c_1(k²)λ − c_0(k²) with
- c_2(k²) = tr J(k²) = −(d_1+d_2+d_3)k² + tr J
- c_1(k²) = tr[adj J(k²)] = b_2 k⁴ + b_1 k² + b_0
- c_0(k²) = det J(k²) = ã_3 k⁶ + ã_2 k⁴ + ã_1 k² + ã_0
- c_2c_1 − c_0 = a_3 k⁶ + a_2 k⁴ + a_1 k² + a_0

Coefficients (eq. 7):
- a_3 = −(d_1+d_2)(d_2+d_3)(d_3+d_1)
- a_2 = (d_1+d_2)(d_1+d_2+2d_3)J_33 + (d_2+d_3)(d_2+d_3+2d_1)J_11 + (d_3+d_1)(d_3+d_1+2d_2)J_22
- a_1 = −[(d_1+d_2)(J_11J_22 − J_12J_21) + (d_2+d_3)(J_22J_33 − J_23J_32) + (d_3+d_1)(J_33J_11 − J_31J_13)] − tr J·[d_1(J_22+J_33) + d_2(J_33+J_11) + d_3(J_11+J_22)]
- a_0 = tr J · tr[adj J] − det J

(eq. 8): b_2 = d_1d_2 + d_1d_3 + d_2d_3; b_1 = −[d_1(J_22+J_33) + d_2(J_33+J_11) + d_3(J_11+J_22)]; b_0 = tr[adj J]

(eq. 9): ã_3 = −d_1d_2d_3; ã_2 = d_1d_2 J_33 + d_2d_3 J_11 + d_3d_1 J_22; ã_1 = −[d_1(J_22J_33 − J_23J_32) + d_2(J_33J_11 − J_31J_13) + d_3(J_11J_22 − J_12J_21)]; ã_0 = det J

Inequality set (5) for a cubic g(y) = a_3y³ + a_2y² + a_1y + a_0 with a_3 < 0, a_0 < 0 (equivalent to ∃ y′ > 0 with g(y′) > 0):
- 0 < a_2² − 3a_1a_3
- 0 < a_2 + √(a_2² − 3a_1a_3)
- 0 < 2a_2³ + 2(a_2² − 3a_1a_3)^{3/2} − 9a_1a_2a_3 + 27a_0a_3²

Inequality set (6), with g(y) = b_2y² + b_1y + b_0:
- b_1 < −√(4b_2b_0)
- 3a_3(b_1 + √(b_1² − 4b_2b_0)) ≤ 2b_0(a_2 + √(a_2² − 3a_1a_3))
- 2b_0(a_2 + √(a_2² − 3a_1a_3)) ≤ 3a_3(b_1 − √(b_1² − 4b_2b_0))
- g((−b_1 − √(b_1² − 4b_2b_0))/(2b_2)) ≤ 0
- g((−b_1 + √(b_1² − 4b_2b_0))/(2b_2)) ≤ 0

**Theorem 1.** n* (N = 3) admits a **Turing-Hopf instability iff** the coefficients (7) satisfy all of (5) and the coefficients (8) fail at least one inequality in (6). It admits a **Turing instability iff** it does not admit a Turing-Hopf instability and the coefficients (9) satisfy all of (5).

Operational form (Lemmas 4–5): Turing-Hopf ⇔ ∃ y″ > 0 with c_1(y″) > 0 and c_2(y″)c_1(y″) − c_0(y″) > 0; Turing ⇔ no Turing-Hopf and ∃ y′ > 0 with c_0(y′) = det J(y′) > 0. (Implemented in `verification/piskovsky_check.py`.)

### Item 22 — Satnoianu, Menzinger, Maini (2000), J Math Biol 41:493–512

A = Jacobian at the uniform state, all eigenvalues in LHP; C = A − k² diag(D). Δ_{i_1…i_p} = principal minor of order p.

**s-stable**: for every principal minor of order q, sgn(Δ) = (−1)^q (i.e. Δ_i < 0, Δ_ij > 0, Δ_ijk < 0). A subsystem violating this is an *activator subsystem*.

**Theorem 1** (necessary): If the kinetic system is s-stable then no Turing bifurcation is possible for any diffusion coefficients.
**Theorem 2**: A is strongly stable (C stable for all D_i ≥ 0) iff A is s-stable.
**Theorem 3** (sufficient): If the kinetic system contains an unstable subsystem, a Turing bifurcation is possible: set the p activator diffusivities small, all but one of the remaining diffusivities also small, and tune the last one through a critical value at which det(−C) = 0.

**Classification.** Turing bifurcation of type p ⇔ ∃ indices with sgn(Δ_{i_1…i_p}) = (−1)^{p+1} and no lower-order type applies.
- **p = 1:** Δ_i = a_ii > 0 for some i (a self-activator).
- **p = 2:** some 2×2 principal minor Δ_ij = a_ii a_jj − a_ij a_ji < 0 (the pair is a saddle when isolated), and no a_ii > 0.

So for our 3×3 Jacobian: Turing possible ⇔ some a_ii > 0, or some 2×2 principal minor negative; otherwise (all a_ii < 0, all Δ_ij > 0, det A < 0) no diffusion choice yields a steady Turing bifurcation. Satnoianu et al. address only steady (real-eigenvalue) bifurcations; wave/Turing-Hopf cases are handled by Piskovsky.
